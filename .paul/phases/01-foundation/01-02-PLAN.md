<objective>
## Goal
Installer shadcn/ui dans les deux apps avec un set minimal (Button, Card) + tokens de design partagés (couleur de base "neutral", police Inter via next/font, CSS variables light/dark, radius, spacing) ; les pages d'accueil utilisent les composants pour prouver la chaîne complète.

## Purpose
Donner aux deux apps une base UI cohérente, accessible et productive avant que les vraies pages arrivent (Phase 2). shadcn/ui = vélocité Claude Code maximale (composants ownés dans le repo, modifiables, pas de runtime lib).

## Output
- shadcn/ui initialisé dans `apps/site` et `apps/academy` (components.json + lib/utils + composants ownés)
- Tokens de design définis via CSS variables (neutral base, light + dark, radius)
- Police Inter chargée via `next/font/google` dans les deux apps
- Composants Button et Card disponibles + utilisés sur les pages d'accueil
- Pages d'accueil mises à jour pour démontrer le système de design (carte avec titre/sous-titre + bouton CTA placeholder)
</objective>

## Notes techniques
- shadcn/ui supporte officiellement Tailwind v4 depuis ~mi-2025 — utiliser le CLI stable `shadcn@latest`
- shadcn Tailwind v4 setup : pas de `tailwind.config.ts` ; tokens via `@theme` directive dans CSS + CSS variables (`--background`, `--foreground`, etc.)
- Le CLI `shadcn add` lit `components.json` ; on peut le créer à la main pour avoir un setup déterministe
- next/font + variable Tailwind : exporter en variable CSS (`--font-sans`) et la référencer dans `@theme`
- Décisions verrouillées (pas de checkpoints) : Inter, base "neutral", radius 0.5rem, dark vars présents mais pas de toggle UI en V1
