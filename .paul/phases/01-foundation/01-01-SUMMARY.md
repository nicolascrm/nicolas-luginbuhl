## Deviations from plan

1. **pnpm 10.33.2 instead of 9.x** — local install was already on 10.x ; using 9.x via corepack would force a download. `packageManager` field set to `pnpm@10.33.2`. Workflows identical.
2. **Node 25.8.2 in current env** — `.nvmrc` left at `20` (LTS, recommended). Build/dev work on 25 ; `.nvmrc` is the project recommendation for new devs / CI.
3. **TypeScript 5.9.3** — TS 6 is now available but plan specified 5.x ; kept on 5.x for tooling compatibility (eslint-config-next 15.x has not validated TS 6 yet).
4. **next-env.d.ts not hand-written** — Next.js auto-generates on first build/dev. File now exists in both apps after `pnpm build`.
5. **`tsconfig.base.json` extras** — added `noEmit: true`, `forceConsistentCasingInFileNames: true`, `allowJs: true` beyond plan minimum (standard Next.js 15 defaults).

## Concerns flagged
