## Notes techniques
- `vercel link` utilise un repertoire de travail comme racine du projet ; pour un monorepo on lance `vercel link` depuis chaque app sous-dossier (`apps/site`, `apps/academy`)
- Vercel détecte automatiquement Next.js + le `package.json` racine du workspace pour le install command
- Vercel CLI 53.x supporte le flag `--project` pour pré-nommer le projet et `--yes` pour non-interactif
- Pour pnpm workspaces, Vercel auto-détecte. Si le install command par défaut casse, fallback : Build Settings → Install Command = `pnpm install --frozen-lockfile`
- pnpm 10 a introduit `onlyBuiltDependencies` dans `package.json` pour approuver les build scripts sans interaction. Alternative : `pnpm approve-builds` interactif.
- Vercel CLI local : 50.37.3 — upgrade recommandé vers 53.x avant ce plan
