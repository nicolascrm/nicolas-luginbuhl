<objective>
## Goal
Établir le monorepo pnpm avec deux applications Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 — `apps/site` (port 3000) et `apps/academy` (port 3001) — toutes deux capables de démarrer localement et d'afficher une page placeholder.

## Purpose
Fondation technique sur laquelle reposent toutes les phases suivantes. Sans monorepo + apps qui boot, rien d'autre n'avance. Optimisé pour vélocité Claude Code (un seul `pnpm dev` lance les deux apps).

## Output
- Monorepo pnpm workspace fonctionnel
- 2 apps Next.js 15 distinctes qui démarrent sur 3000 et 3001
- Tailwind v4 configuré dans les deux apps
- TypeScript strict partagé via `tsconfig.base.json`
- README minimal expliquant la structure et comment lancer
</objective>

## Notes techniques
- Next.js 15 utilise App Router par défaut, Turbopack en dev (`next dev --turbo`)
- Tailwind CSS **v4** : configuration via `@import "tailwindcss"` dans CSS, plus de `tailwind.config.ts` requis
- Vérifier les versions à jour avant install : Next 15.x, React 19.x, Tailwind 4.x
- pnpm workspace : un `pnpm-workspace.yaml` à la racine, chaque app a son propre `package.json`
</context>

    - `"name": "site"`, `"private": true`, `"version": "0.0.0"`
    - Scripts :
      - `"dev": "next dev --turbopack -p 3000"`
      - `"build": "next build"`
      - `"start": "next start -p 3000"`
      - `"lint": "next lint"`
      - `"typecheck": "tsc --noEmit"`
    - dependencies : `next` (15.x), `react` (19.x), `react-dom` (19.x)
    - devDependencies : `typescript` (5.x), `@types/node`, `@types/react`, `@types/react-dom`, `tailwindcss` (4.x), `@tailwindcss/postcss` (4.x), `postcss`, `eslint`, `eslint-config-next`

    **`apps/site/tsconfig.json`** :
    ```json
    {
      "extends": "../../tsconfig.base.json",
      "compilerOptions": {
        "plugins": [{ "name": "next" }],
        "paths": { "@/*": ["./*"] }
      },
      "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
      "exclude": ["node_modules"]
    }
    ```

    **`apps/site/next.config.ts`** : config Next.js 15 minimale exportée avec types :
    ```ts
    import type { NextConfig } from "next";
    const nextConfig: NextConfig = {};
    export default nextConfig;
    ```

    **`apps/site/postcss.config.mjs`** :
    ```js
    export default { plugins: { "@tailwindcss/postcss": {} } };
    ```

    **`apps/site/app/globals.css`** (Tailwind v4 — pas de `@tailwind base/components/utilities`) :
    ```css
    @import "tailwindcss";
    ```

    **`apps/site/app/layout.tsx`** :
    - Root layout avec `<html lang="fr">` (FR par défaut, sera overridé en Phase 2 par next-intl)
    - Import de `./globals.css`
    - Metadata basique : `title: "Nicolas Luginbuhl"`, `description: "Builder Ops/Growth — HubSpot, n8n, automatisation, IA"`
    - `<body>` qui rend `{children}` avec une classe Tailwind de base (`min-h-screen bg-white text-slate-900 antialiased`)

    **`apps/site/app/page.tsx`** :
    - Page d'accueil placeholder avec `<main>` Tailwind

    - Ne pas activer Turbopack pour le build (uniquement dev) — `next build` reste sur le bundler de prod par défaut
